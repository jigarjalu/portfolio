# Jigar J Jalu — Premium Personal Portfolio

A complete, modern, responsive, and visually impressive personal portfolio website for **Jigar J Jalu**, built with React, Vite, Tailwind CSS, and Anime.js.

## 🚀 Features

- **Cyber-Editorial Aesthetic**: Designed with Obsidian Black (`#06070A`), Electric Violet (`#7957FF`), Laser Cyan (`#00E5FF`), and high-contrast typography.
- **Interactive Branding & Logo**: Custom JJJ gradient monogram branding and animated entrance effects.
- **Featured Projects**: Showcasing **Buddy Hub** as the core platform alongside Aarambh Brand, Zaree by Asha Rajkot, The Pestro Pavilion, and The Mountain View with exact project screenshots.
- **Advanced Scroll Animations**: Lightweight Intersection Observer supporting smooth slide-in from left/right and fade-in reveals.
- **Magnetic Hover Effects**: Interactive buttons and project cards gently pull toward the cursor.
- **Typewriter Hero Heading**: Dynamic writing animation on the main hero headline.
- **Contact Form**: Functional inquiry form with validation, success feedback, and mailto fallback.

---

## 🛠️ Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser at `http://localhost:3000`.

## 🌐 Deploying to Vercel (`jigarjalu.vercel.app`)

1. **Push your code to GitHub**:
   - Create a repository on GitHub (e.g., `jigarjalu/portfolio`).
   - Push your project files to the repository.

2. **Deploy on Vercel**:
   - Go to [Vercel Dashboard](https://vercel.com).
   - Click **Add New...** > **Project** and import your GitHub repository.
   - Vercel will automatically detect Vite and configure the build settings (`npm run build`).
   - Click **Deploy**.

3. **Configure Custom Domain (`jigarjalu.vercel.app`)**:
   - In your Vercel project dashboard, navigate to **Settings** > **Domains**.
   - Enter `jigarjalu.vercel.app` (or your preferred Vercel subdomain/custom domain) and click **Add**.
   - Vercel will instantly provision and assign the domain to your live portfolio.
